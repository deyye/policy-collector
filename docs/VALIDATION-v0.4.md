# v0.4 改动与验证记录

验证日期：2026-09-09。基线：主分支 `c64c4c0`。本版保留其浙江全量翻页与江苏列表实现，在此基础上修复入库质量问题并增加省级来源、模型配置入口。

## 改动和原因

| 问题 | 本版行为 |
|---|---|
| 浙江翻页中途失败，前面发现的链接未返回 | 保留成功页的候选，入队继续处理，来源记录错误 |
| 接口重复返回同一页被当作采完 | 停止循环并报错，明确未确认历史列表采完 |
| 同页多个构建单元可能选错 | 优先信息列表单元；仅调用官网同源公开网关，不执行网页脚本 |
| 福建文号在正文外，湖南文号被 Word 内联标签切碎 | 解析独立元数据块、合并段落内联文本，避免用正文引用文号替代 |
| 陕西、湖南正文混入导航，联合发文单位漏提 | 增加正文容器适配；优先正文落款，支持多个发文单位 |
| 无法定位正文或附件不支持解析仍显示成功 | `documents_incomplete` / `attachments_unparsed` 计入部分完成，进入复核；附件返回 HTML 错误页算下载失败 |
| 单个项目批复自动视为投资政策，“会议制度”“备案管理办法”被误判 | 区分普遍适用制度与个案批复；申报/报送标题不再直接触发投资相关 |
| 失败项永远优先，旧文件无法轮转复查 | 未检查候选优先，其余按最近检查时间轮转，保留 `--retry-only` |
| 同一来源内容重复时无法补齐元数据 | 仅补原为空的字段，留下 `metadata_backfill` 记录，不覆盖人工分类、不新增内容版本 |
| 模型需改 YAML，空白 .env 覆盖默认值 | 新增网页和 CLI 配置、最小连接检查；空白环境示例项不覆盖默认值 |
