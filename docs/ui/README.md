# 界面改版说明

本次在 v0.5 基础上统一 Flask 前端视觉，使用深蓝、白色、灰蓝和少量砖红，适合政策研究与国企业务工作台。所有图标为内联 SVG，使用本机中文字体，不依赖远程字体、图片或前端框架。

## 查看效果

下载并用浏览器打开 [preview.html](preview.html)，可切换工作总览、政策资料库、政策详情、采集来源、运行记录与模型配置六个页面；缩小窗口可查看响应式布局。预览由实际 Jinja 模板渲染，使用隔离目录中的合成样例。表单输入、查询及提交已禁用，预览不连接数据库或模型服务，分类导航只跳转资料库，不执行筛选。

实际使用仍在仓库根目录运行：

```bash
python -m policy_collector.cli web --open
```

## 主要变化

- 工作总览：真实数据库指标、四类政策入口、最近入库、待复核与运行入口。
- 政策资料库：集中搜索筛选、完整标题、分类与复核状态、横向滚动表格。
- 政策详情：正文阅读区、侧栏分类依据和人工复核、附件与原件、来源及历史版本。
- 采集来源：以站点与栏目组织信息，接入说明折叠展示，保留现有运行操作。
- 运行记录：中文状态标识，保留材料不完整、附件异常和模型回退等问题信息。
- 模型配置：分组表单、接入步骤和连接检查，密钥不回显。
- 公共布局：统一导航、标题、按钮、空状态及焦点样式；窄屏使用横向导航与单列布局，表格在自身容器内滚动。

本次仅修改模板、样式和说明文件，采集、分类、去重、模型 API 与数据库逻辑沿用 v0.5。

## 验证与限制

- 现有 47 项测试通过。
- Flask 测试客户端检查六个页面与空结果页，均返回 HTTP 200。
- 保留来源运行、人工复核、模型保存与连接检查表单的字段、路由和 CSRF 隐藏字段；静态预览移除 CSRF 字段并禁用操作。
- 浏览器环境限制本地页面访问，本次未完成真实浏览器视觉与移动端交互验证。静态预览用于查看设计，不能作为浏览器验收记录。
- 未触发真实官网采集或付费模型调用。
